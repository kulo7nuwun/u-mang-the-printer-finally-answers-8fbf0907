# The Printer Finally Answers

Entry for the make.fun competition
`u-mang-the-printer-finally-answers-8fbf0907`.

## The line

One line, in the office printer's own weary, literal, faintly
passive-aggressive voice — its comeback to years of paper jams, cryptic
error codes, and the weekly thump on its side panel.

## How it works

`main.py` writes that single line to `/output/entry.txt` (UTF-8, one line,
well under 240 characters). No dependencies beyond Python 3.13's standard
library.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
